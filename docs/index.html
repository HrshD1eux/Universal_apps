Frequently Asked Questions

Direct answers to common questions.

Does it really work 100% offline?

Yes. The desktop app is powered by Tauri and Rust with local HTML/JS. No internet connection is needed to calculate loans, decode QR codes, parse JSON, or merge PDFs. PDF workers are bundled locally inside the binary.

How does the PDF Merger handle mismatched page sizes?

The Universal PDF Merger includes native vector page standardization. It scales and centers mixed-dimension pages (e.g. A4 portrait mixed with wide scanned documents) into uniform A4 or Letter sheets so pages never jump from tiny to huge in viewers.

How do software updates work?

The app features an automated GitHub Release update checker. Whenever a new version is published to GitHub Releases, an in-app popup notifies you with a direct download link and release highlights.

Is this project free and open source?

Yes, Universal Apps is licensed under the MIT License. The complete source code, build scripts, and workflows are public on GitHub.
