## 📦 Installation & Setup

### 📋 Prerequisites

#### System Requirements
- **OS**: Windows 10+, macOS 10.13+, or Linux (Ubuntu 18.04+)
- **RAM**: Minimum 2GB, Recommended 4GB+
- **Storage**: 500MB free space

#### Required Software
1. **Node.js** (v20.0 or higher)
   - [Download Node.js](https://nodejs.org/)
   - Verify: `node --version` and `npm --version`

2. **Rust** (1.80 or higher)
   - [Install Rust](https://www.rust-lang.org/tools/install)
   - Verify: `rustc --version` and `cargo --version`

3. **Platform-Specific Requirements**

   **Windows Only:**
   - Microsoft Edge WebView2 Runtime
   - Wix Toolset v4 (for installer creation)
   
   **macOS Only:**
   - Xcode Command Line Tools: `xcode-select --install`
   
   **Linux Only:**
   - `libwebkit2gtk-4.1-dev`
   - `build-essential`
   - `curl`
   - `wget`
   - `file`
   - `libssl-dev`

### 🚀 Quick Start (Development)

```bash
# Step 1: Clone the repository
git clone https://github.com/HrshD1eux/Universal_apps.git
cd Universal_apps

# Step 2: Install dependencies
npm install

# Step 3: Start development server
npm run dev:tauri

# Step 4: Open in browser (if not auto-opened)
# Navigate to http://localhost:9002
```

### 📦 Production Build

#### Build for Your OS
```bash
# Build optimized native binary
npm run tauri build

# Output location:
# - Windows: src-tauri/target/release/bundle/msi/
# - macOS: src-tauri/target/release/bundle/dmg/
# - Linux: src-tauri/target/release/bundle/deb/
```

#### Build for All Platforms (Requires Cross-Compilation)
```bash
# Build for Windows
npm run tauri build -- --target x86_64-pc-windows-msvc

# Build for macOS
npm run tauri build -- --target x86_64-apple-darwin

# Build for Linux
npm run tauri build -- --target x86_64-unknown-linux-gnu
```

### 🔧 Advanced Configuration

#### Environment Setup
```bash
# Create .env.local file
touch .env.local

# Add configurations (optional)
NEXT_PUBLIC_APP_VERSION=0.1.0
NEXT_PUBLIC_ENABLE_ANALYTICS=true
```

#### Development Tips
```bash
# Type checking
npm run typecheck

# Linting
npm run lint

# Build without running
npm run build

# Full development with hot reload
npm run tauri dev
```

## 💻 Usage & Examples

### Example 1: Financial Calculation
```
Goal: Calculate SIP returns for ₹5,000/month for 20 years at 12% annual return

Steps:
1. Open "SIP Calculator"
2. Monthly Investment: ₹5,000
3. Annual Return: 12%
4. Investment Period: 20 years
5. View: Total Amount, Total Interest, Monthly Growth Chart

Result: ~₹44,00,000+ investment value
```

### Example 2: Unit Conversion
```
Goal: Convert 5.5 miles to kilometers

Steps:
1. Open "Unit Converter"
2. Select Category: "Length"
3. Input: 5.5 miles
4. Output: 8.85 km (automatic)

Other available conversions on same screen:
- To meters: 8,850 m
- To feet: 29,040 ft
- To nautical miles: 4.78 nmi
```

### Example 3: PDF Processing
```
Goal: Merge 3 PDFs and add page numbers

Steps:
1. Open "PDF Studio"
2. Select "PDF Merger"
3. Upload files in order
4. Merge & Save
5. Re-upload merged PDF
6. Select "PDF Page Numbers"
7. Add numbering format
8. Download final PDF

Privacy: All processing happens locally on your machine
```

## 🎨 Design Philosophy

### 🏆 Core Principles

1. **Performance First** ⚡
   - Sub-millisecond calculations
   - Instant UI responsiveness
   - Zero network latency

2. **Privacy by Default** 🔐
   - Zero servers, zero tracking
   - All data stored locally (IndexedDB)
   - No telemetry or analytics
   - GDPR compliant

3. **Aesthetic Excellence** 🎨
   - Modern vibrant gradients
   - Smooth 60fps animations
   - Intuitive dark/light themes
   - Responsive design (mobile to desktop)

4. **Developer-Friendly** 👨‍💻
   - Clean, modular codebase
   - Type-safe TypeScript throughout
   - Well-documented components
   - Easy to extend with new tools

### 🎭 Visual Design Elements

- **Color Palette**: Dynamic gradient backgrounds
- **Typography**: Inter font family (400-800 weights)
- **Spacing**: Consistent 4px/8px grid system
- **Shadows**: Subtle elevation with semi-transparent overlays
- **Animations**: Framer Motion for smooth transitions
- **Icons**: Lucide React (300+ icons available)
